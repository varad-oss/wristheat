## Method notes

- The **watch skill could not run** in the cloud workspace: its proxy blocks YouTube and the Gemini API. The videos were watched through the Claude app's browser on your computer instead (transcripts + 30–40 frames each).
- **Live data checks** were keyless calls, mostly from that browser. **No AWS calls were made**: there are no credentials here, so AWS capability claims rest on documentation.
- **Tags:** FACT (sourced) · INFERENCE (reasoned) · HYPOTHESIS (untested). Capability labels: VERIFIED · VERIFIED-BUT-CONSTRAINED · PLAUSIBLE-UNTESTED · UNSUPPORTED.
- **Scores are decision aids,** not predictions of winning.
